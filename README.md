## Ruang Lingkup

Sistem basis data ini digunakan untuk mendukung pengelolaan data pada klinik, seperti data pasien, dokter, pemeriksaan, dan informasi pelayanan klinik. Database dirancang agar data dapat disimpan dan dikelola secara terstruktur serta akses pengguna dapat dibatasi sesuai kebutuhan.
