MariaDB merupakan sistem manajemen basis data relasional yang digunakan untuk menyimpan dan mengelola data. MariaDB dapat digunakan melalui command line maupun aplikasi berbasis web seperti phpMyAdmin.

# 4. HASIL LATIHAN

## 4.1 Script SQL Rerunnable

File `p01_lingkungan_25430039.sql` dibuat agar dapat dijalankan kembali tanpa harus membuat ulang objek yang sudah tersedia.

Script menggunakan:

```sql

```

dan:


Penggunaan `IF NOT EXISTS` membuat script lebih aman untuk dijalankan berulang kali karena database atau user yang sudah ada tidak perlu dibuat ulang.

Script telah diuji dengan menjalankannya sebanyak dua kali dan berhasil tanpa masalah.

# 5. ANALISIS

## 5.1 Analisis Hak Akses Pengguna

Pembuatan beberapa user dengan hak akses berbeda menunjukkan bahwa MariaDB dapat membatasi aktivitas berdasarkan privilege yang diberikan.

User `mhs_039` memiliki akses pada database `kopma_039`, sedangkan `tamu_039` hanya diberikan hak `SELECT`. Dengan pengaturan tersebut, setiap user hanya dapat menjalankan operasi sesuai dengan izin yang dimilikinya.

## 5.2 Perbedaan Error 1044, 1045, dan 1142

**Error 1044** menunjukkan bahwa user tidak memiliki akses terhadap database tertentu. Pada praktikum, error ini terjadi ketika `dev_039` mencoba menggunakan database yang tidak diberikan hak akses.

**Error 1045** berkaitan dengan kegagalan autentikasi ketika proses login. Error ini dapat terjadi apabila informasi akun atau password yang digunakan tidak sesuai.

**Error 1142** menunjukkan bahwa user tidak memiliki privilege untuk menjalankan perintah tertentu. Pada praktikum, error tersebut muncul ketika `tamu_039` mencoba menjalankan perintah `CREATE TABLE`.

## 5.3 Analisis Akun Developer

User `dev_039` dibuat khusus untuk database proyek `klinik_039`. Ketika user tersebut mencoba mengakses `kopma_039`, sistem memberikan Error 1044.

Hal tersebut menunjukkan bahwa privilege dapat dibatasi berdasarkan database yang diperlukan oleh user.

## 5.4 Analisis Script Rerunnable

Penggunaan `IF NOT EXISTS` membuat script dapat dijalankan kembali tanpa harus menghapus database atau user yang sudah dibuat.

Dengan demikian, proses instalasi dan persiapan lingkungan praktikum menjadi lebih mudah untuk diulang.
