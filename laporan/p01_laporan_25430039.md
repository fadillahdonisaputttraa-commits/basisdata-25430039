**5. Analisis**

Error 1044 menunjukkan bahwa pengguna tidak memiliki akses terhadap database tertentu.

Error 1045 menunjukkan bahwa proses login atau autentikasi gagal karena informasi akun yang digunakan tidak sesuai.

Error 1142 menunjukkan bahwa pengguna tidak memiliki hak untuk menjalankan perintah tertentu, seperti `CREATE TABLE`.

Dari pengujian tersebut dapat diketahui bahwa hak akses database dapat diberikan sesuai kebutuhan masing-masing pengguna.
